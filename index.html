What's Changed

Current Version

  • Refreshed the interface styling with cleaner grouped toolbars, softer cards, sharper inputs, and a more polished AKNES-style workspace hierarchy.
  • Turned the top control area into an open-by-default disclosure panel and removed the old Fit view button for a cleaner header.
  • Made the sidebar sections collapsible too, so Legend, Image, Board Image, Keycap, and Links can be folded away while you focus on one area.
  • Changed the sidebar sections to start closed by default, so the page opens with a cleaner, less overwhelming settings column.
  • Added Ctrl+A and Cmd+A to select all visible keys when you're not typing in a field.
  • Corrected the ISO Enter silhouette so the stepped shape matches a proper ISO enter key and still responds to corner radius and corner scale.
  • Fixed ISO Enter preview and export rendering so the stepped shape stays visible in Export Preview, keeps its full bounds, and uses a better-aligned text box.
  • Kept the ISO Enter outline visible during Export Preview fallback and matched the canvas Enter path to the same stepped proportions as the on-page SVG shape.
  • Made ISO Enter notch depth and notch height profile-based printer settings, so each keycap profile can save its own real Enter measurements and drive the Enter shape directly.
  • Fixed ISO Enter corner controls so the outer corners still round while the inner notch stays tight instead of growing into a six-corner blob.
  • Further constrained ISO Enter corner radius to the real stepped body dimensions, so large corner values cannot turn the whole key into an over-rounded pill shape.
  • Separated the ISO Enter outer body shape from the tunable artwork mask so the key keeps its proper rounded stepped outline while the image corners still remain adjustable.
  • Added Shift/Ctrl multi-select and Selected ZIP export for exporting only chosen keys.
  • Changed artwork corner radius to use circular pixel corners instead of stretched/oblong percentage corners.
  • Fixed narrow side-panel sliders so the value boxes no longer overlap the slider controls.
  • Added printer profile Image and Board X/Y/Z calibration so profiles can globally nudge and scale artwork placement.
  • Added a draggable and resizable board-image overlay so board art can be positioned directly on the keyboard.
  • Changed image drag-and-drop so dropping on a key loads that key, while dropping on the board/stage loads the board image.
  • Board image direct resize can now scale down to 0, Fit keyboard resets board art across the full keyboard, and clicking away flattens the edit overlay.
  • Added a Move board image checkbox so board art only captures drag/move clicks when you explicitly turn board editing on.
  • Keycap profile switching now drives the Printer Settings key-size table directly, so changing the selected profile swaps the mm values to that exact profile's saved key-face sizes.
  • Printer profile name, DPI, and key-size mm fields now auto-save while you type, so a page refresh keeps the latest values for each profile.
  • Added keyboard shortcuts so Delete or Backspace clears images from the selected key or keys, and Ctrl+Z or Cmd+Z runs Undo when you're not typing in a field.
  • Set the default Corner radius to 0 and Corner scale to 100 for a clean square starting point.
  • Fixed live and exported image placement so Fill and Stretch use the full visible key area instead of the smaller inner artwork box.
  • Added per-key Corner radius, Corner scale, and Image area X/Y/Z controls so selected keys can each have their own artwork shape and face size.
  • Moved Printer Settings into the sidebar so profile settings can be changed live without a popup covering the keyboard.
  • Fixed ISO Enter board-image placement so the live preview uses the full L-shaped area instead of the old inset rectangle.
  • Fixed ISO Enter corner radius and corner scale so the Enter artwork mask, outline, and board slice now respond to those sliders in live preview and export.
  • Improved ISO Enter corner rounding so the outside corners can round fully without being limited by the smaller inner notch radius.
  • Constrained ISO Enter artwork back inside the key bounds so larger corner-scale values can no longer spill outside the Enter key box.
  • Fixed the printer profile reference image so it no longer blocks key selection, per-key image uploads, or drag-and-drop images.
  • Fixed hosted profile HTML so Printer Settings always starts closed after refresh or redeploy.
  • Added Undo for recent edits, layout changes, imports, clears, images, and custom layout moves.
  • Added larger PNG export scales up to 12x.
  • ZIP exports now preserve raw per-key source images for better reload quality.
  • Preview image placement and export cropping now use matching placement logic.
  • Added Export Preview mode to show keys using the same canvas renderer as PNG export.
  • Export Preview hides the normal HTML preview layers so transparent exports do not show helper key labels underneath.
  • Added a support link under the Discord and AKNES links.
  • Improved Export Preview sharpness with higher-resolution rendering and high-quality canvas image smoothing.
  • Board images now keep the original upload for Export Preview and PNG/ZIP output while using the smaller copy for the normal live editor.
  • Live preview labels now shrink to fit single words instead of splitting labels like Pause and Delete across lines.
  • Increased the artwork corner radius in live preview and PNG export so printed key images have rounder corners.
  • Moved the Corner radius slider into the Image section and made it round only the printed artwork/image area, not the visible key body.
  • Changed Corner radius to a 0-100 scale so printer tuning is proportional to each key face.
  • Added locked Printer Settings with three local keycap profiles for mm face sizes and DPI-based export sizing.
  • Re-added Corner scale so the rounded artwork face can be resized separately from the image scale.
  • Printer Settings now re-lock every time they open, and text fitting follows the same printer profile face area as images.
  • Printer Settings now require the password before the settings window opens.
  • Added main-page printer profile selection, per-profile reference images, and hashed password checking for Printer Settings.
  • Added session unlock for Printer Settings and a Download HTML with Profiles button for baking hosted profile settings into the HTML file.

Layouts

  • Improved ANSI and ISO 60%, 60% arrows, 65%, 75%, TKL, Full, and Lemokey P1 Pro ISO layouts.
  • Fixed ISO Enter shape, rounded clipping, ISO extra keys, right shift sizing, and arrow cluster alignment.
  • Added custom layout editing with 0.25u snap, key add/remove, size presets, and custom reset.

Design Tools

  • Added board-wide images, per-key images, drag-and-drop images, fit/fill/stretch controls, and source ZIP reload.
  • Added text alignment, text X/Y movement, legend gap, font loading, text opacity, and shine-through cutout controls.
  • Added select-all editing for applying text opacity and cutout settings across the whole board.

Export And Project Files

  • ZIP load/save restores layout settings, key text, images, font settings, colors, and board images.
  • Added transparent or colored key backgrounds for print-friendly exports.
  • Added page background color, AKNES branding, Discord/AKNES links, and this changelog.
